# Shorif Mahmud Abdullah — Portfolio

Personal portfolio site built with plain HTML, CSS and JavaScript (no build step).

Live at: https://shorif-mahmud-abdullah.github.io/

## Files
- `index.html` — page content
- `style.css` — styles (dark/light theme, responsive)
- `script.js` — theme toggle, typing effect, scroll animations, project filters
- `assets/profile.jpg` — profile photo
- `assets/Shorif_Mahmud_Abdullah_CV.pdf` — downloadable CV

## Changing your photo
Replace `assets/profile.jpg` with your new picture, keeping the same file name. Any size or shape works; it is cropped to a circle automatically. (If you use a PNG, name it `profile.png` and change `assets/profile.jpg` in `index.html`, in the `<img>` tag and the `og:image` line.) If the old photo still shows after publishing, hard-refresh the page (Ctrl+Shift+R).

## Updating
Edit `index.html`, commit and push to `main`. GitHub Pages redeploys automatically in about a minute.
